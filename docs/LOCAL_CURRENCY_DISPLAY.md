# Location-based Dramio Pass estimates

The Pass price on the creator landing page, its activation button, promotional comparison/conflict prices, and the unowned Account card follow the visitor's Cloudflare IP-country metadata. Taiwan uses TWD (`NT$`), Hong Kong HKD, Japan JPY, and supported countries use their primary mapped currency. Interface language does not determine location: Traditional Chinese is shared by Taiwan and Hong Kong. VPNs can affect the detected country. No browser GPS prompt is used.

`GET /api/display-currency` runs at the outer Worker before the account Durable Object. It trusts only `request.cf.country`, never client headers, query parameters or browser storage. Responses are `private, no-store`; converted rates alone are cached by currency for six hours. Other methods return 405. The standalone server and local Worker requests have no trusted location and return exact HKD.

Rates come from [Frankfurter v2](https://frankfurter.dev/), using `/v2/rate/HKD/{currency}`. The fixed provider URL receives no application account/payment fields. Pair, positive finite rate, calendar date and a seven-day freshness window are validated. Provider requests have a 3.5-second timeout. Unknown countries, provider failures, missing or stale rates fall back to the exact HKD price. Fresh estimates are marked `≈`; currencies use their normal decimal precision. No estimated conversion is presented as a guaranteed bank charge.

The regular Pass remains HK$88; a valid promotion keeps its existing server-quoted HKD amount. The localized billing note states the actual HKD charge and explains that issuer rates and fees can differ. These display quotes never enter Checkout requests, receipts, wallet/earnings calculations, Stripe settlement validation or withdrawal/bank-currency estimates. Existing HKD financial proofs and retry keys remain unchanged. Live creator payouts stay paused, and the current test/live payment mode is preserved during release.

Validation covers trusted/spoofed location, cache separation, freshness and provider failure; Taiwan/Japan/Hong Kong display; discounted and Account prices; HKD Checkout payloads; and narrow/RTL/high-value currency layouts. Local tests use fixed rate fixtures, not live exchange rates.
